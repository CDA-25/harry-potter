# Harry Potter SPA

## Overview
This project is a Single Page Application (SPA) themed around the Harry Potter universe. It utilizes React for building the user interface and TypeScript for type safety.

## Project Structure
```
harry-potter-spa
├── src
│   ├── components       # Contains reusable React components
│   ├── pages            # Contains main page components
│   ├── styles           # Contains CSS styles
│   ├── main.ts          # Entry point of the application
│   └── index.html       # Main HTML file
├── package.json         # npm configuration file
├── tsconfig.json        # TypeScript configuration file
└── README.md            # Project documentation
```

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   cd harry-potter-spa
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm start
   ```

## Usage
Open your browser and navigate to `http://localhost:3000` to view the application.
